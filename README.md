## ✨ What is DealScout AI?

> 🛍️ **DealScout AI** helps shoppers determine whether a product is actually worth buying.

Simply enter a product name or paste a product link.

The platform analyzes the product and provides:

| 💰 Price | ⭐ Value | 🛍️ Alternatives |
|:---:|:---:|:---:|
| Compare stores | Worth-It Score | Cheaper options |

---

## 🚀 Features

| Feature | Description |
|---|---|
| 🔎 Smart Search | Search products by name or URL |
| 💰 Price Comparison | Compare prices across stores |
| ⭐ Worth-It Score | See whether the product is a good deal |
| 🛍️ Alternatives | Find cheaper similar products |
| 📈 Price History | Analyze previous prices |
| 🤖 AI Recommendation | Buy, Wait, or Consider Alternative |
| ❤️ Favorites | Save products for later |
| 🔗 Share | Share deals with friends |
| 🌙 Dark Mode | Modern dark/light interface |
| 📱 Responsive | Works on mobile and desktop |
